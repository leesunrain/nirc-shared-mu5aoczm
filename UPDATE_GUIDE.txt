기존 Vercel 프로젝트: oneclick-app-deployer-safe-v14

2. Vercel 기존 프로젝트 Settings > Git에서 연결 저장소와 Production 브랜치를 확인합니다.
3. 연결된 기존 GitHub 저장소의 해당 브랜치에 압축 해제한 파일을 업로드하고 커밋합니다. 새 Vercel 프로젝트를 생성하지 마세요.
4. 기존 Vercel 프로젝트의 Deployments에서 Production 배포 완료를 확인합니다.
5. 기존 URL에서 v1.7.3 표시 및 기존 기능, 앱 목록, 홈 바로가기, 설정 보존을 확인합니다.

변경: 기존 앱 업데이트에서 ZIP 파일명 불일치만으로 차단하지 않습니다.
Vercel 프로젝트 ID, 프로젝트명, Production URL 서버 검증 및 GitHub 기존 저장소 검증은 유지합니다.
파일명이 다른 경우 추가 사용자 확인을 요구합니다.
주의: ZIP 내부 파일이 실제로 해당 앱용인지 확인해야 합니다.

배포기 자체 projectId, PWA manifest/start_url/scope 및 사용자 데이터 저장 구조의 서버측 상태는 별도 확인이 필요합니다.
이 ZIP은 실제 배포를 수행하지 않습니다.
